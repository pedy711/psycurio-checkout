# PsyCurio Checkout — Hiring Task

A mouse-driven shop checkout scene (shelf, counter, cash register, cashier) for
therapist-guided exposure work, plus a therapist control panel with SUDS logging.

Work in progress — full documentation (how to run, usability decisions,
architecture notes) lands with the final documentation step. The git history
follows the development process step by step.

- Unity 6000.3.21f1 LTS, Universal Render Pipeline, build target Android
  (IL2CPP, ARM64)
- Scene: `Assets/Scenes/Shop.unity`
- Docs: [docs/AI-LOG.md](docs/AI-LOG.md), `docs/DECISIONS.md` (final step)
